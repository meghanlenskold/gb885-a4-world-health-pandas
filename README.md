# gb885-a4-world-health-pandas

## What This Is
A pandas-based analysis notebook completed for GB885 (Python Fundamentals). The notebook uses country-level world health data to complete task such as indexing, sorting, filtering, grouping, etc.

## Business Question
The notebook is framed around a fictional scenario where I act as an analyst for a global infant and maternal health advocacy group, preparing data insights for the group's founder ahead of a presentation to the UN. The underlying questions center on infant and maternal mortality patterns across countries and how they related to factors such as language, GDP per capita, and out-of-pocket healthcare spending.

## Data Source
The dataset is pulled directly from a public GitHub-hosted CSV. It has 194 countries included and 18 indicators.

## How to Run It
Open in Google Colab. Run all cells in order. The notebook loads the dataset directly from its URL, so no download is needed.
